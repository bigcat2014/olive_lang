\section{Ambiguity}
\paragraph{
    Ambiguity is recognized between some of the regexes listed below.
    This ambiguity is solved in the lexer by taking the longest match or through regex precedence.
    The longest match is to pick the regex that matches the most characters (greedy matching),
    while the precedence resolution is to define a precedence of regexes such that in the case where
    two regexes match the same span one is preferred.
}
\subsection{Examples}
\paragraph{Some examples of ambiguous matches include:}
\begin{itemize}
    \item "else" matches both \begin{math}<else>\end{math} and \begin{math}<ident>\end{math}. Solved with precedence.
    \item "1.2e3" matches as either \begin{math}<float\_const>\end{math} followed by an \begin{math}<ident>\end{math} or as a \begin{math}<scientific>\end{math}. Solved with longest match.
    \item "r\textbackslash"abc\textbackslash"" matches as either an \begin{math}<ident>\end{math} followed by a \begin{math}<string\_literal>\end{math} or as just a \begin{math}<string\_literal>\end{math}. Solved with longest match.
\end{itemize}
